# RobotExpressive

Model by [Tomás Laulhé](https://www.patreon.com/quaternius), released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Modifications by [Don McCurdy](https://donmccurdy.com/): three facial expression morph targets, FBX2GLTF conversion, and material cleanup.

Source: [Three.js r186 RobotExpressive model](https://github.com/mrdoob/three.js/tree/r186/examples/models/gltf/RobotExpressive).

This project uses the included rigged glTF model and its Idle, Walking, Wave, Dance, Jump, and ThumbsUp animation clips. The three expression morphs are not phoneme-specific; speech animation is approximate.
